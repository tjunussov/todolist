## Requirements

### Requirement: Todo-список в браузере без шага сборки
Приложение ДОЛЖНО работать как один статический HTML-файл, открываемый напрямую в браузере, без npm/сборки; Vue ДОЛЖЕН подключаться UMD/global-сборкой через `<script src>`.

#### Scenario: Открытие файла напрямую
- **WHEN** пользователь открывает `index.html` в браузере (без локального сервера и без сборки)
- **THEN** приложение рендерится и работает полностью

### Requirement: Управление задачами
Пользователь ДОЛЖЕН мочь добавлять новую задачу по тексту, отмечать задачу выполненной/невыполненной и удалять задачу из списка.

#### Scenario: Добавление задачи
- **WHEN** пользователь вводит текст и подтверждает (Enter или кнопка)
- **THEN** задача появляется в списке в статусе "не выполнена"

#### Scenario: Отметка выполнения
- **WHEN** пользователь переключает чекбокс у задачи
- **THEN** статус задачи (`done`) меняется соответственно

#### Scenario: Удаление задачи
- **WHEN** пользователь нажимает кнопку удаления у задачи
- **THEN** задача пропадает из списка

### Requirement: Персист в localStorage
Список задач ДОЛЖЕН сохраняться в `localStorage` при любом изменении и восстанавливаться из него при загрузке страницы.

#### Scenario: Перезагрузка страницы
- **WHEN** страница перезагружается после добавления/изменения задач
- **THEN** список задач восстанавливается из `localStorage` в том же виде, в каком был перед перезагрузкой
